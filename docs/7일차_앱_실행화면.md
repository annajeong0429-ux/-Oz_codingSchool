1. 회원가입

URL: /signup

API: POST /api/v1/users/signup

설명: 이메일, 이름, 부서, 성별, 전화번호, 비밀번호 입력 후 가입.

이미지 표시


2. 로그인

URL: /login

API: POST /api/v1/users/login

설명: 이메일과 비밀번호로 로그인. 성공 시 JWT 액세스 토큰 발급.

이미지 표시


3. 환자 목록 조회

URL: /patients

API: GET /api/v1/patients

설명: 로그인 후 환자 목록 조회. 이름 검색, 성별/나이 필터 기능 제공. 상단에 사용자 이름과 부서 표시.

이미지 표시


4. 진료기록 등록

URL: /patients/{patient_id}/medical-records/create

API: POST /api/v1/patients/{patient_id}/medical-records

설명: 차트 번호, 증상, X-Ray 이미지 업로드 후 진료기록 등록. 이미지 미리보기 제공.

이미지 표시


5. 진료기록 상세 조회 및 AI 폐렴 예측

URL: /medical-records/{record_id}

API: GET /api/v1/medical-records/{record_id}

API: GET /api/v1/medical-records/{record_id}/ai-analysis

API: POST /api/v1/medical-records/{record_id}/ai-analysis

설명: 진료기록 상세 정보 및 X-Ray 이미지 표시. AI 모델(ConvNeXt + DenseNet OR 앙상블)로 폐렴 예측. 폐렴 여부, Confidence, 사용 모델명 반환.

예측 결과:


폐렴 여부: Positive (폐렴 감지)
Confidence: 70.53%
사용 모델: convnext_densenet_OR


이미지 표시
